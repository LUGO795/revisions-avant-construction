Qui fait quoi ?

Chaque langage a un seul rôle. Quand vous hésitez sur l'endroit où écrire une ligne,
demandez-vous : est-ce du contenu, de l'apparence ou une réaction ?

HTML La structure

Il dit ce qu'il y a sur la page :
un menu, des sections, un formulaire, des images.
Le navigateur, Google et les lecteurs d'écran le lisent en premier.

Côté TSSR : c'est le câblage et le rack. Sans lui, rien ne tient.

CSS L'apparence

Il dit à quoi ça ressemble : couleurs, polices, espacements, mise en page mobile, animations. Il ne change jamais le contenu.

Côté TSSR : c'est la baie bien rangée et étiquetée.
Même matériel, mais lisible.

JS Le comportement

Il dit ce qui se passe quand :
un clic, un défilement, l'envoi d'un message.
Il lit et modifie le HTML et les classes CSS.

Côté TSSR : c'est le script PowerShell qui automatise ce qu'on ferait à la main.

1. Le navigateur lit le HTML→ 2. Il applique le CSS→ 3. Il exécute le JavaScript

HTML01

HTML, leçon 1 : Le squelette d'une page

Toute page HTML5 suit le même plan : une déclaration, une racine, une tête invisible et un corps visible.

HTMLÉpisode 01Maîtrisée ✓

L'essentiel

  • <!DOCTYPE html> en première ligne : sans lui, le navigateur passe en « mode quirks » et lit mal le CSS.
  • <html lang="fr"> annonce la langue aux lecteurs d'écran et à Google.
  • Le <head> parle au navigateur (encodage, titre, description), le <body> parle au visiteur.
  • meta viewport est indispensable au responsive : sans elle, le mobile affiche une miniature du site.

À retenir : Une balise ouverte se referme toujours, dans l'ordre inverse : <main><h1>…</h1></main>.

HTML02

HTML, leçon 2 : Relier les ressources dans le head

Le portfolio s'appuie sur des polices, Bootstrap, Font Awesome, des favicons et ses propres scripts : tout se déclare dans le head.

HTMLÉpisode 01Maîtrisée ✓

L'essentiel

  • <link rel="stylesheet"> charge une feuille CSS, <script src> charge un fichier JavaScript.
  • rel="preconnect" ouvre la connexion vers Google Fonts à l'avance : la page s'affiche plus vite.
  • display=swap montre le texte tout de suite avec une police de secours.
  • Chemin relatif (images/favicon-32x32.png) pour vos fichiers, adresse complète (https://…) pour un CDN.

À retenir : Une ressource mal nommée donne une erreur 404 dans la console (F12). C'est le premier test de l'épisode 01.

HTML03

HTML, leçon 3 : Les balises sémantiques

Une balise sémantique décrit le rôle d'un bloc. Le portfolio est découpé en nav, main, sept section et un footer.

HTMLÉpisodes 02, 03, 05 et 12Maîtrisée ✓

L'essentiel

  • <nav> pour le menu, <main> pour le contenu principal (une seule fois par page), <footer> pour le pied de page.
  • Chaque <section> a un id (cible des liens du menu) et un titre relié par aria-labelledby.
  • Un seul <h1> par page, puis des <h2> par section, des <h3> dedans : on ne saute pas de niveau.
  • <div> et <span> ne veulent rien dire : on les garde pour la mise en forme.

À retenir : Choisissez une balise pour son sens, jamais pour son apparence. L'apparence, c'est le travail du CSS.

HTML04

HTML, leçon 4 : Liens, ancres et images

Les liens du menu sautent vers les sections, les captures des outils .exe se chargent à la demande, les téléchargements s'ouvrent ailleurs.

HTMLÉpisodes 03 et 09Maîtrisée ✓

L'essentiel

  • href="#skills" vise l'élément qui porte id="skills" : c'est une ancre.
  • target="_blank" ouvre un nouvel onglet ; on ajoute toujours rel="noopener" par sécurité.
  • alt décrit l'image pour qui ne la voit pas. Une image purement décorative reçoit alt="".
  • width et height réservent la place, loading="lazy" retarde le chargement des images hors écran.

À retenir : Une icône Font Awesome est décorative : aria-hidden="true", et c'est le texte du lien qui porte le sens.

HTML, leçon 6 : L'accessibilité dans le HTML

Un recruteur peut naviguer au clavier ou avec un lecteur d'écran. Quelques attributs suffisent à rendre la page compréhensible.

HTMLÉpisodes 02, 03, 08 et 13Vigilance 1Maîtrisée ✓

L'essentiel

  • Le lien d'évitement « Passer au contenu principal » apparaît à la première pression sur Tab.
  • aria-label donne un nom à un bouton qui n'a qu'une icône (le burger, le thème).
  • aria-expanded dit si le menu mobile est ouvert ; Bootstrap le met à jour tout seul.

CSS01

CSS, leçon 1 : Sélecteurs, cascade et spécificité

Le CSS cible des éléments puis leur applique des règles.
Quand deux règles se contredisent, la plus spécifique gagne.

CSSÉpisodes 02, 03, 08 et 10Vigilance 2Maîtrisée ✓

L'essentiel

  • Sélecteur d'élément (body), de classe (.glass-card), d'id (#mainNav), d'attribut ([data-theme="light"]), d'état (:hover, :focus-visible).
  • Spécificité : un id pèse plus que 10 classes, une classe plus que 10 éléments.
  • À spécificité égale, la règle écrite le plus bas l'emporte.
  • !important écrase tout et rend les corrections difficiles : c'est l'origine de la vigilance 1.

À retenir : Pour qu'un état visuel change, préférez ajouter une classe (.active, .scrolled) plutôt que d'empiler les sélecteurs.

CSS02

CSS, leçon 2 : Les variables et le thème clair

Toutes les couleurs, rayons, ombres et polices du portfolio sont des variables. Changer de thème revient à changer leurs valeurs.

CSSÉpisodes 02 et 20Vigilance 6Maîtrisée ✓

L'essentiel

  • On déclare une variable dans :root avec deux tirets : --clr-accent: #3b82f6;.
  • On l'utilise avec var(--clr-accent), partout où il faut cette couleur.
  • Le bloc [data-theme="light"] redéfinit les mêmes variables : toute la page bascule d'un coup.
  • Les noms décrivent un rôle (--clr-text-soft), pas une couleur (--gris).

À retenir : Vérifiez chaque couleur de texte dans les deux thèmes : un contraste d'au moins 4,5 : 1 est exigé (vigilance 6).

CSS03

CSS, leçon 3 : Le modèle de boîte

Chaque élément est une boîte : son contenu, puis le padding, la bordure et la marge. Le reset du portfolio rend ces calculs prévisibles.

CSSÉpisodes 02 et 05Maîtrisée ✓

L'essentiel

  • padding : l'espace intérieur, entre le contenu et la bordure.
  • margin : l'espace extérieur, entre la boîte et ses voisines.
  • box-sizing: border-box : la largeur annoncée inclut padding et bordure. Plus de mauvaises surprises.
  • rem suit la taille de texte du visiteur, px reste fixe : préférez rem pour les tailles et les espacements.

À retenir : Ouvrez les outils de développement (F12), onglet Éléments : le schéma de la boîte montre padding, bordure et marge en couleurs.

CSS04

CSS, leçon 4 : Flexbox et Grid

Deux outils de mise en page. Flexbox aligne sur une ligne, Grid découpe en lignes et en colonnes.

CSSÉpisodes 03, 04, 05 et 06Maîtrisée ✓

L'essentiel

  • display: flex range les enfants côte à côte ; flex-wrap: wrap les fait passer à la ligne.
  • display: grid + grid-template-columns: 1fr 1fr crée deux colonnes égales.
  • gap espace les enfants, sans marges à calculer.
  • Bootstrap (.row, .col-lg-4) est lui-même construit en Flexbox.

À retenir : Une ligne d'éléments (statistiques, boutons, liens du menu) : Flexbox. Une grille de cartes ou un tableau d'infos : Grid.

CSS05

CSS, leçon 5 : Le responsive

Le portfolio est testé de 1920 à 320 pixels. Les media queries, clamp() et aspect-ratio font l'essentiel du travail.

CSSÉpisodes 04, 10, 12 et 20Vigilances 3 et 5Maîtrisée ✓

L'essentiel

  • @media (max-width: 767.98px) applique des règles seulement sous cette largeur. Le portfolio suit les paliers Bootstrap : 991.98, 767.98, 575.98 px.
  • clamp(2.4rem, 6vw, 4.2rem) : une taille fluide, avec un minimum et un maximum.
  • aspect-ratio: 900 / 540 garde les proportions des captures (vigilance 3).
  • overflow-x: clip sur html, body supprime le défilement horizontal (vigilance 5).

À retenir : Testez avec F12 puis l'icône mobile : 1440, 768 et 375 px au minimum. Aucune barre de défilement horizontale ne doit apparaître.

CSS, leçon 6 : Transitions et animations

CSSÉpisodes 03, 04, 05 et 17Vigilance 4Maîtrisée ✓

JS01

JavaScript, leçon 1 : Charger et organiser le JavaScript

Le JavaScript du portfolio est découpé en 12 modules.
Chacun est une fonction qui s'exécute tout de suite et garde ses variables pour lui.

JavaScriptÉpisodes 03 et 14Maîtrisée ✓

L'essentiel

  • Les scripts principaux sont placés en fin de <body> :
    le HTML existe déjà quand ils s'exécutent.
  • (function () { … })(); est une IIFE : une fonction exécutée aussitôt, dont les variables ne débordent pas.
  • const pour ce qui ne change pas, let pour ce qui change. On n'utilise plus var.
  • Deux scripts qui déclarent le même const au niveau global : le second plante en entier. L'IIFE évite ce piège.

À retenir : Ouvrez la console (F12) après chaque module : zéro erreur rouge, c'est le test 9 de la construction.

JavaScript, leçon 2 : Lire et modifier la page (le DOM)

Le DOM, c'est le HTML vu par JavaScript.
On sélectionne un élément, puis on change son texte, ses attributs ou ses classes.

JavaScriptÉpisodes 03, 08 et 12Vigilance 1Maîtrisée ✓

L'essentiel

  • getElementById('mainNav') trouve un élément par son id, querySelectorAll('.reveal') trouve tous ceux qui correspondent.
  • textContent change le texte, setAttribute change un attribut.
  • classList.add, remove et toggle gèrent les classes : le CSS fait le reste.
  • forEach parcourt une liste d'éléments, un par un.

À retenir : Le JS change une classe, le CSS décide de la couleur. C'est exactement la précaution de la vigilance 1.

JS03

JavaScript, leçon 3 : Réagir aux événements

Un clic, un défilement, l'envoi d'un formulaire : addEventListener branche une fonction sur chaque événement.

JavaScriptÉpisodes 03, 11 et 12Maîtrisée ✓

L'essentiel

  • element.addEventListener('click', fonction) : la fonction s'exécute à chaque clic.
  • 'scroll' se déclenche très souvent : { passive: true } garde le défilement fluide.
  • e.preventDefault() bloque le comportement par défaut, comme le rechargement à l'envoi d'un formulaire.
  • Une même fonction peut servir à plusieurs événements : setActive au défilement et au chargement.

À retenir : Le paramètre e (l'événement) contient des informations utiles : e.target est l'élément cliqué.

JS04

JavaScript, leçon 4 : Mémoriser avec localStorage

Le thème choisi, la langue, le nom personnalisé : le portfolio s'en souvient d'une visite à l'autre grâce au localStorage.

JavaScriptÉpisodes 03, 13 et 15Maîtrisée ✓

L'essentiel

  • localStorage.setItem('theme', 'light') enregistre une valeur texte dans le navigateur.
  • localStorage.getItem('theme') la relit ; elle vaut null si rien n'est enregistré.
  • || 'dark' donne une valeur par défaut quand rien n'est enregistré.
  • try { … } catch (e) {} évite une erreur si le navigateur bloque le stockage (navigation privée).

À retenir : localStorage ne stocke que du texte.
Pour un objet, on passe par JSON.stringify à l'écriture et JSON.parse à la lecture.

JavaScript, leçon 5 : Observer le défilement

IntersectionObserver prévient le JavaScript quand un élément entre à l'écran.
Le portfolio s'en sert pour les apparitions et les barres de compétences.

JavaScriptÉpisodes 05 et 06Maîtrisée ✓

L'essentiel

  • On crée un observateur avec une fonction appelée à chaque changement de visibilité.
  • e.isIntersecting vaut true quand l'élément devient visible.
  • obs.unobserve() arrête la surveillance : l'animation ne se joue qu'une fois.
  • Si le navigateur ne connaît pas l'outil, on affiche tout directement : aucun contenu ne reste caché.

À retenir : threshold: 0.12 veut dire « 12 % de l'élément visible ». Plus économe qu'un calcul à chaque défilement.

JavaScript, leçon 6 : Envoyer des données avec fetch

Le formulaire envoie le message à Formspree sans quitter la page. C'est le module 9, le plus complet du portfolio.

Les 6 vigilances, langage par langage

Les six corrections apportées pendant la série. Chacune illustre une règle vue plus haut.

  1. Lien actif du menu JSHTMLép. 08

    Le JS ajoute la classe .active au lieu d'écrire une couleur, et pose aria-current="location" pour les lecteurs d'écran. Voir leçons J2 et H6.

  2. Icône du badge .exe CSSép. 10

    font-size: inherit : l'icône reprend la taille de son parent au lieu d'une valeur héritée de Bootstrap. Voir leçon C1.

  3. Captures .exe entières CSSép. 10

    height: auto; aspect-ratio: 900 / 540 : la boîte garde les proportions de l'image, rien n'est rogné. Voir leçon C5.

  4. Réduction des animations CSSJSép. 17

    prefers-reduced-motion en CSS, et behavior: 'auto' en JS pour le retour en haut. Voir leçon C6.

  5. Débordement horizontal mobile CSSép. 20

    html, body { overflow-x: clip; } : plus de défilement de côté, et la navbar collante continue de fonctionner. Voir leçon C5.

  6. Contrastes du thème clair CSSép. 20

    Les variables du thème clair sont foncées pour atteindre le niveau WCAG AA (4,5 : 1 pour le texte). Voir leçon C2.
